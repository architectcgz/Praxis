# 校验规则

- 校验只在输入层进行。输入层必须在数据进入内部调用链之前，完成该入口所需的校验。
- 校验方法写在接收输入的调用层，由调用层决定检查哪些内容；禁止将校验方法或校验逻辑放在 `contracts` 中。
- 输入的规范化、默认值补充与校验由输入层一次完成；内部直接使用处理后的值，不重复清洗或补值。
- 输入校验通过后，内部禁止重复校验，包括再次调用 `Validate`、重复检查同一字段、递归校验对象或仅为校验而重新解析数据。
- 跨函数、跨包、对象复制或类型转换不构成重新校验的理由；不得在内部新增“已校验”标志、校验模式或包装层来绕过此规则。
- 校验失败由输入层直接返回可定位的错误，不将非法输入传入内部，也不通过静默修复或回退掩盖问题。
