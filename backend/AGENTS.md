# Praxis 后端开发约定

## 编码约定

- 注释默认使用中文，Praxis 自身错误信息默认使用英文。
- Go 代码格式遵守根目录 `AGENTS.md` 的复合字面量换行约定。

## 验证

- 在 `backend/` 目录执行 `go build ./...`、`go vet ./...`、`go list ./...`。
- 遵守根目录不保留测试文件、不新增或运行自动化测试的约定；需要数据验证时使用独立临时目录，不使用真实用户数据。
- 修改 Wails 签名后执行 `go run -tags bindings .` 生成绑定，不手工编辑 `wailsjs/`。随后在前端执行 `npm run check`。
- 不自动启动开发服务，启动前必须取得用户明确授权。
