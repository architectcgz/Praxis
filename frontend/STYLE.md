# Praxis Frontend Style Guide

状态：活跃规范

这份文档定义 Praxis 前端的整体视觉与交互风格。所有新增或修改的前端组件、页面、交互状态和样式，都必须遵守这里的规则。

## 设计方向

Praxis 工作区采用暖灰 + 深绿的工具型界面：密集、高效、安静，优先保证长期使用时的信息密度和扫描效率。

### 核心理念

- **暖灰底色**：页面背景 `#efefec`，纸面 `#f7f7f5`，侧栏 `#e7e7e3`，营造温和、不刺眼的长期工作环境。
- **深绿强调**：主操作和选中态用深绿 `#0e6b52`，沉稳、专注，不张扬，区别于蓝色系的通用工具。
- **紧凑布局**：界面字号 14px 为主，阅读正文 15px，行高 1.5～1.65，间距紧凑，信息密度与长期可读性平衡。
- **开放层级**：侧栏、主区通过细分隔线和背景色差分隔，不用厚边框或投影；卡片只用于弹窗、独立工具和列表项，不包裹整个页面区块。
- **无装饰**：不用渐变、光球、噪点、荧光色、厚重拟物或营销式大标题。

### 适用场景

这套理念覆盖整个 Praxis 前端：工作区、代理详情、项目列表、设置页、对话框。所有新增页面和组件必须遵守下列设计令牌和布局规则。

## 设计令牌

设计令牌统一在 `src/styles/global.css` 的 `:root` 中定义。组件样式优先使用令牌，不在局部创建作用相同的近似值。

### 颜色

| 用途 | 令牌 | 值 |
|---|---|---|
| 页面背景 | `--bg` | `#efefec` |
| 侧栏背景 | `--side` | `#e7e7e3` |
| 纸面/卡片 | `--paper` | `#f7f7f5` |
| 主文字 | `--ink` | `#1b1b19` |
| 次级文字 | `--muted` | `#6a6a64` |
| 辅助文字 | `--faint` | `#8d8d86` |
| 细分隔线 | `--line` | `#d8d8d2` |
| 强分隔线 | `--line-strong` | `#c8c8c0` |
| 悬停填充 | `--fill` | `#deded8` |
| 选中背景 | `--selected` | `#e1e1db` |
| 主操作 | `--accent` | `#0e6b52` |
| 主操作深色 | `--accent-ink` | `#085443` |
| 提醒 | `--warn` | `#9a6700` |
| 错误 | `--danger` | `#b42318` |

**色彩规则**

- 深绿 `--accent` 只用于主操作按钮、链接、选中指示器和焦点边框，不作为装饰色使用。
- 提醒和错误色保持语义，不用于主题装饰。
- 背景色从 `--bg`（最深）→ `--side` → `--paper`（最浅）形成视觉层级。
- 状态不能只依靠颜色表达，必须同时提供文字、图标或形状差异。

### 动效时长

| 用途 | 令牌 | 当前值 |
|---|---|---|
| 标准过渡 | `--motion-duration` | `140ms` |
| 强调入场 | `--motion-duration-emphasized` | `180ms` |
| 加载旋转 | `--motion-duration-spinner` | `900ms` |

背景、边框、颜色和轻微缩放使用 `--motion-duration`，内容入场使用 `--motion-duration-emphasized`。所有动效必须在 `prefers-reduced-motion: reduce` 下被禁用或压缩。

### 间距指导

项目使用紧凑间距，优先保证信息密度：

- 组件内部紧凑间距：`4px`、`6px`、`8px`
- 组件间常规间距：`10px`、`12px`、`16px`
- 区块分隔与留白：`20px`、`24px`
- 页面级留白：固定值，不使用 `vh` 或 `clamp()`

间距数值应保持视觉节奏的一致性，避免在相邻区域混用相近但不同的值（如 `10px` 和 `12px`）。

### 阴影

| 用途 | 定义 |
|---|---|
| 顶部栏 | `0 1px 2px rgba(0, 0, 0, 0.04)` |
| 浮层 | `0 2px 8px rgba(0, 0, 0, 0.08)` |
| 弹窗 | `0 4px 16px rgba(0, 0, 0, 0.12)` |

阴影必须保持低扩散、低透明度，只用于表达空间层级，不作为装饰。

### 圆角

| 用途 | 值 |
|---|---|
| 输入框、按钮、列表行 | `6px` |
| 卡片、面板 | `6px` |
| 弹窗、浮层 | `8px` |
| 徽标、标签 | `4px` |

圆角保持克制，不使用大圆角（>10px）或完全直角。

### 组件尺寸

| 组件 | 尺寸规范 |
|---|---|
| 按钮高度（标准） | `32px` |
| 按钮高度（紧凑） | `28px` |
| 输入框高度 | `32px` |
| 列表行高度（标准） | `32px` |
| 列表行高度（紧凑） | `28px` |
| 图标按钮最小尺寸 | `28px × 28px` |
| 图标按钮触控尺寸（移动端） | `32px × 32px` |
| 顶部栏高度 | `42px` |
| 侧栏最小宽度 | `240px` |
| 主内容最大阅读宽度 | `920px` |

### 动效缓动

所有过渡动画使用以下缓动函数：

| 用途 | 值 |
|---|---|
| 标准过渡 | `cubic-bezier(0.4, 0, 0.2, 1)` |
| 入场 | `cubic-bezier(0, 0, 0.2, 1)` |
| 出场 | `cubic-bezier(0.4, 0, 1, 1)` |

示例：

```css
transition: background-color var(--motion-duration) cubic-bezier(0.4, 0, 0.2, 1);
```

## 字体与排版

- 使用系统字体栈：`"Segoe UI", "PingFang SC", "Noto Sans SC", "Microsoft YaHei", sans-serif`。
- 不引入品牌字体作为默认界面字体。
- `letter-spacing` 必须为 `0`，不使用负字距或装饰性字距。
- 全局基础字号使用 `var(--font-size-base)`，当前为 `14px`，基础行高为 `1.5`。
- 界面控件和侧栏主体使用 `var(--font-size-ui)`，当前为 `14px`。
- 消息、Markdown 和输入内容使用 `var(--font-size-body)`，当前为 `15px`，行高使用 `1.6～1.65`。
- 次级说明、状态和时间使用 `var(--font-size-secondary)`，当前为 `12px`。
- 极少量指标和紧凑标签使用 `var(--font-size-caption)`，当前为 `11px`，不得继续缩小。
- 代码和路径使用 `var(--font-size-code)`，当前为 `12px`。
- 页面级标题使用 `var(--font-size-title)`，当前为 `22px`。
- 字号 token 统一定义在 `src/styles/global.css` 的 `:root` 中，组件样式不得重复创建同语义的局部字号变量。
- 标题使用固定字号，并在断点处切换到另一档固定字号；不使用 `vw` 或 `clamp()` 让字号随视口连续变化。
- 紧凑面板、列表和弹窗中的标题应与容器密度匹配，不使用 Hero 级字号。
- 通过字号、字重和颜色建立信息层级，不依赖全大写或过宽字距制造强调。
- 长文本必须换行或省略，不能溢出容器、遮挡相邻内容或改变固定控件的尺寸。

## 布局与密度

- 工作界面保持紧凑但不拥挤，优先支持快速扫描、比较和重复操作。
- 顶部栏保持 `42px` 高度，使用实色背景和细底边。
- 侧栏使用低对比度背景和稳定宽度，主内容区使用弹性宽度并设置合理的最大阅读宽度。
- 工具栏、按钮、输入框、列表行和固定格式区域必须具有稳定尺寸，动态内容不能导致布局跳动。
- 列表行应整行可点击；悬停、选中和聚焦只改变颜色、背景或边框，不改变几何尺寸。
- 可滚动区域预留稳定的滚动槽（`--scroll-gutter: 10px`），滚动条使用低对比度滑块和透明轨道。
- 空状态和加载状态使用无装饰背景的简洁图标与短文案，不额外创建卡片层级。

### 页面结构类

- `.main-panel`、`.region`：分配可用空间，不负责滚动或页面内边距。
- `.page`：只控制内容宽度和排版，默认最大阅读宽度为 `920px`，可通过 `--page-width` 调整；不设置高度、裁剪或入场动画。
- `.scroll-region`：区域的主要滚动所有者，使用稳定滚动槽；不能嵌套在 `.page` 内。
- `.page-header`：页面头部。常规固定头部与 Scroll 为兄弟；设置与模型配置页在单一 Scroll 内使用 sticky 头部，窗口高度不超过 `560px` 时随内容滚动。

示例：

```css
.settings-content {
    --page-width: 920px;
}
```

公共容器契约在 `workspace/layout.css` 中定义，feature 拥有自己的内容内边距和局部排版。具体职责遵循 [`LAYOUT.md`](LAYOUT.md)。

## 层叠顺序

层叠顺序统一使用 `src/styles/global.css` 的 token：

| 用途 | Token |
|---|---|
| 基础内容 | `--z-base` |
| 提升内容 | `--z-raised` |
| 菜单与选择器 | `--z-popover` |
| 顶部栏 | `--z-sticky` |
| Modal | `--z-modal` |

局部样式不得使用未定义的数值 `z-index`。

## 材质、边框与圆角

- 顶部栏和侧栏使用实色背景，不使用半透明或 `backdrop-filter`。
- 普通分隔线使用 `--line`，只表达结构边界，不作为装饰。
- 普通输入框、按钮和列表行使用 `6px` 圆角。
- 普通文本标签不使用胶囊容器；仅状态、筛选条件和短标签可以使用紧凑徽标。
- 弹窗可以使用 `8px` 圆角和柔和浮层阴影。
- 阴影必须低扩散、低透明度，只用于顶部栏、浮层和弹窗。
- 禁止大面积厚重阴影、粗边框和高对比度浮动面板。

## 图标与控件

- 默认使用 `lucide-react`，不手绘已有语义的 SVG，也不使用 ASCII 字符模拟图标。
- 返回、关闭、添加、删除、刷新、搜索等熟悉操作优先使用图标。
- 仅图标按钮必须提供 `aria-label`；不熟悉的图标同时提供 `title`。
- 图标尺寸、线宽和颜色应与相邻控件保持一致。
- 主操作使用深绿实心按钮，次操作使用浅灰或透明按钮，危险操作使用低透明度红色按钮。
- 二元设置使用开关或复选框，模式切换使用分段控件，数值使用输入框、步进器或滑块，选项集合使用菜单或下拉框。
- 工具按钮默认使用低对比度背景，悬停或激活时切换为深绿语义。
- 按钮按下可以轻微缩放，但不能产生明显位移。

## 表单与浮层

- 表单标签使用次级文字，placeholder 使用辅助文字，不与已填写内容争夺层级。
- 输入框聚焦时只改变边框颜色或背景色，不添加外侧 `outline`、发光或额外 `box-shadow`。
- 错误提示使用完整圆角边框、浅红背景、图标和文字，不使用左侧色条。
- 弹窗使用实色白色表面、完整边框和柔和阴影，不使用背景模糊。
- 菜单、选择器和弹出面板应贴近触发控件，保持清晰的视觉归属。
- 点击浮层外部或按 `Escape` 应关闭非阻塞浮层。
- 危险操作必须使用明确的红色语义，并在执行前提供清晰确认状态。

## 内容呈现

- 正文优先使用平面排版，通过段落间距和标题层级组织内容。
- 代码使用等宽字体和低对比度背景；代码块与表格使用细边框和紧凑工具栏。
- 表格在窄容器中允许横向滚动，不压缩到无法阅读。
- 主要内容和辅助操作之间保留稳定间距，工具按钮不能遮挡正文。
- 成功、提醒、错误和加载状态使用一致的图标、颜色与文字层级。

### 消息气泡

| 元素 | 样式规范 |
|---|---|
| 用户消息背景 | `--paper` 或 `#fff` |
| 代理消息背景 | `--bg` 或浅灰 |
| 消息内边距 | `12px 16px` |
| 消息圆角 | `6px` |
| 消息间距 | `10px` |
| 用户名/角色标签 | 字号 `var(--font-size-secondary)`，颜色 `--muted`，字重 `600` |
| 时间戳 | 字号 `var(--font-size-caption)`，颜色 `--faint`，等宽字体 |

- 消息气泡不使用阴影或厚边框。
- 连续的同角色消息可合并头部信息，只保留首条的用户名和时间。
- 消息内代码块使用 `--paper` 背景和 `1px solid var(--line)` 边框。

### 工具调用卡片

| 元素 | 样式规范 |
|---|---|
| 卡片背景 | `--paper` 或 `#fff` |
| 卡片边框 | `1px solid var(--line)` |
| 卡片圆角 | `6px` |
| 工具名称 | 字号 `var(--font-size-code)`，字重 `600`，等宽字体 |
| 参数/输出 | 字号 `var(--font-size-code)`，颜色 `--muted`，等宽字体 |
| 执行中状态 | 左侧色条 `2px solid var(--accent)` 或转圈图标 |
| 错误状态 | 左侧色条 `2px solid var(--danger)` 或错误图标 |
| 折叠按钮 | 图标按钮，`20px × 20px`，放在右上角 |

- 工具调用卡片内代码 diff 使用 `+` / `-` 前缀和浅绿/浅红背景。
- 折叠状态只显示工具名称和一行摘要，展开后显示完整参数和输出。
- 执行中状态用旋转图标或左侧色条，不闪烁、不全局遮罩。

### 代码块

| 元素 | 样式规范 |
|---|---|
| 背景 | `#fbfbfa` 或 `--paper` |
| 边框 | `1px solid var(--line)` |
| 圆角 | `6px` |
| 内边距 | `12px` |
| 字体 | `var(--mono)`，字号 `var(--font-size-code)`，行高 `1.6` |
| 行号 | 颜色 `--faint`，右侧留 `12px` 间距 |
| 复制按钮 | 图标按钮，`24px × 24px`，放在右上角 |
| 语法高亮 | 低对比度色彩，不使用荧光色 |

- 代码块最大高度 `400px`，超出部分滚动。
- 复制按钮默认半透明，悬停时完全可见。
- 行号可选，不强制显示。

### 时间轴

- 选中指示器覆盖容器底边。
- 不使用背景色变化表达选中，只用底边和颜色。

## 交互与动效

- 背景、边框、颜色和轻微缩放过渡通常为 `140ms` 左右，内容入场不超过 `180ms`。
- 动效只用于说明状态变化和空间关系，不用于装饰或延迟反馈。
- 加载过程不使用长时间淡出、连续滚动或阻塞式动画。
- 所有动效都必须在 `prefers-reduced-motion: reduce` 下被压缩或禁用。

## 响应式

- 超过 `1180px` 时显示完整三栏；`1180px` 及以下收起 Agent 侧栏，`860px` 及以下收起项目侧栏，主内容占满可用宽度。
- 项目侧栏收起时，顶部栏左侧保留 `Menu` 图标入口；导航抽屉沿用侧栏视觉和控件，宽度不超过 `320px`，项目/会话列表滚动，底部设置入口固定可见。
- `720px` 以下减少页面边距，保持主要内容和主要操作可见。
- `460px` 以下压缩顶部栏和弹窗间距，表单单列排列，操作按钮使用等宽布局。
- 移动端触控目标必须可操作：图标按钮不小于 `32px`，主要按钮不小于 `36px` 高度。
- 不通过缩小到难以阅读的字号解决空间不足，优先换行、重排或隐藏次要信息。

## 无障碍

- 所有交互元素必须可通过键盘操作，并具有清晰的可访问名称。
- 图标不能作为状态或操作含义的唯一载体。
- 文字、图标和背景之间保持足够对比度。
- 焦点反馈必须可辨识，同时遵守输入框不使用外侧发光的规则。
- 禁用状态不能只降低透明度到难以辨识，仍需保持内容可读。

## 禁止项

- 不使用文字或 ASCII 字符模拟图标。
- 不使用负字距、视口比例字号、装饰性渐变或背景光球。
- 不使用左侧色条表达选中状态；工具调用卡片的执行中/错误状态可用 `2px` 左侧色条，但必须同时提供图标或文字。
- 不使用树形连接线或粗重边框表达选中状态。
- 不嵌套卡片，不把普通页面区块设计成浮动卡片。
- 不绕过现有颜色令牌、Lucide 图标和输入框聚焦规则。

## 验证

前端样式或组件变更完成后，至少运行：

```bash
cd frontend
npm run build
```

同时检查桌面端、`1180px`、`860px`、`720px`、`460px` 断点的两侧、`320px` 最小窗口和短窗口，以及键盘焦点、错误态、空状态、加载态和 `prefers-reduced-motion`。
