# Praxis Frontend Style Guide

状态：活跃规范

这份文档定义 Praxis 前端的整体视觉与交互风格。所有新增或修改的前端组件、页面、交互状态和样式，都必须遵守这里的规则。

## 设计方向

Praxis 工作区是密集、高效、安静的工具型界面，优先保证长期使用时的信息密度和扫描效率。它有两个主题：

- **白天（`data-theme="light"`）**：结构面中性、阅读面微暖的工具台。
- **夜间（`data-theme="dark"`）**：暗色驾驶舱，用信号绿统一强调与活动状态。

主题只切换令牌取值，组件样式不写主题分支。两套颜色令牌的名称完全一致，定义位置见下节。

### 核心理念

- **明度分层**：窗口外沿 → 结构面 → 阅读面 → 内嵌块 → 浮层，五级表面。结构面与阅读面只差一档明度，最大的明度跨度留给仪器域。
- **仪器域凹一层**：终端、diff、代码块和工具参数使用仪器域材质。它永远**比阅读面更暗一层**——白天是凹下去的冷调台面，夜间是比阅读面更深的墨底。域分离靠明度方向、等宽字体和内阴影，**不靠颜色反转**，所以白天展开工具不会在纸面上砸出黑块。
- **有先后的动作按顺序留在正文**：工具调用排成活动账本，不占整行卡片；需要你决策的事固定在输入区上方。
- **紧凑布局**：界面字号 13.5px 为主，阅读正文 15.5px，行高 1.72，间距紧凑。
- **有限色彩**：主色只用于主操作、链接、选中与焦点；活动信号色只在「正在发生」时出现；提醒与危险保持语义。
- **无装饰**：不用渐变、光球、噪点、荧光色、半透明玻璃或营销式大标题。

### 颜色：滚动与阴影

| 用途 | 令牌 |
|---|---|
| 滚动条滑块 / 悬停 | `--scrollbar-thumb` / `--scrollbar-thumb-hover` |
| 下拉箭头（data URI） | `--select-chevron` |
| 顶栏 / 浮层 / 弹窗阴影 | `--shadow-top` / `--shadow-float` / `--shadow-modal` |

**色彩规则**

- 主色 `--accent` 只用于主操作按钮、链接、选中指示和焦点，不作为装饰色。
- `--live` 只在「正在发生」出现（运行中的点、进度、流式状态），不得用于静态信息。
- 提醒和危险保持语义，不用于主题装饰。
- 仪器域令牌只在仪器域容器（`.instrument`）内使用，不能用于纸张内容。
- 状态不能只依靠颜色表达，必须同时提供文字、图标或形状差异。
- 夜间主题的禁用态不得只降 `opacity`，需使用固定色，否则会掉出 4.5:1。

### 排版

内容字号只有**三档**，步长约 1.13；元信息与机器文字共用最小的那一档，靠字体族、字重和颜色区分，而不是靠彼此只差 4% 的字号去「制造层级」。

| 用途 | 令牌 | 值 |
|---|---|---|
| 小字档：元信息、时间、状态、脚注、结构标签、代码与路径、活动账本 | `--font-size-meta` | `12px` |
| 界面档：控件、列表、消息头名称 | `--font-size-ui` | `var(--font-size-base)` = `13.5px` |
| 阅读档：消息正文、Markdown 段落、表格内容 | `--font-size-body` | `15.5px` |
| 面板内标题 | `--font-size-heading` | `17px` |
| 次级页面标题 | `--font-size-title` | `22px` |
| 页面级标题、空状态主标题 | `--font-size-display` | `30px` |

| 行高 | 令牌 | 值 |
|---|---|---|
| 阅读正文 | `--line-height-body` | `1.72` |
| 元信息行 | `--line-height-meta` | `1.5` |
| 代码与机器输出 | `--line-height-code` | `1.7` |

| 字距 | 令牌 | 值 |
|---|---|---|
| 结构标签（仅 12px 微型标签） | `--track-micro` | `0.08em` |

**排版规则**

- 使用系统字体栈：`"Segoe UI", "PingFang SC", "Noto Sans SC", "Microsoft YaHei", sans-serif`；等宽栈为 `--mono`，末尾保留中文回退，避免 CJK 落到衬线字体。
- 严禁新增 `11` / `12.5` / `13` 这类与相邻档只差 4% 的字号。需要区分时用字重、颜色或字体族，不用字号。
- `letter-spacing` 必须为 `0`，唯一例外是 12px 结构标签使用 `--track-micro`。
- `--font-size-display` 只用于页面级标题和空状态主标题，不进密集列表或面板内标题。
- 字重只用 `400 / 600 / 650 / 700` 四档。
- 标题使用固定字号并在断点切换，不使用 `vw` 或 `clamp()`。
- 等宽内容的行高一律使用 `--line-height-code`，不要在局部写 `1.6` / `1.65` / `1.75` 这类近似值。
- 长文本必须换行或省略，不能溢出容器或改变固定控件尺寸。

### 元信息密度

元信息（时间、状态、耗时、token、行数、退出码）是辅助层，不得铺成数据堆。

- Token 用量直接展示总计、输入、输出、缓存读取和缓存写入，会话累计额外展示缓存率；分项保持完整，空间不足时换行。精确计数与其他次要指标写进 `title` 悬浮提示。
- 同一屏里的「操作元信息」——回合脚注、仪器域脚注、账本行右列——必须使用同一档字号、同一档行高和相近的对比度，否则看起来会是两种东西。
- 状态词只在**非正常结束**时出现（失败、已取消、进行中）；正常完成不占位置。

### 阴影

| 用途 | 令牌 |
|---|---|
| 顶部栏 | `--shadow-top` |
| 浮层（菜单、通知、错误横幅） | `--shadow-float` |
| 弹窗 | `--shadow-modal` |

阴影必须低扩散、低透明度，只用于表达空间层级。夜间主题的 `--shadow-top` 是一条 `inset` 内高光，用于给浮起表面提供纵深。

|---|---|---|
| 标准过渡 | `--motion-duration` | `140ms` |

## 主题

- 主题体现在 `<html data-theme="light|dark">`，由 `features/workspace/useColorTheme.ts` 维护，偏好存于 `themePreference.ts`。
- 首帧之前由 `index.html` 的内联脚本决定主题，避免启动闪白或闪黑。
- 用户显式选择后固定；未选择过时跟随 `prefers-color-scheme`。
- 顶栏提供切换入口（图标按钮，带 `aria-pressed` 与可访问名称）。
- 新增颜色令牌必须同时在 `global.css` 与 `theme-dark.css` 中定义；只在一侧定义会让另一个主题漏色。
- 仪器域不是「固定深色」，而是「永远比阅读面更暗一层」，所以它的全部令牌都要在两个主题里分别给出取值，不能两个主题共用同一组深色。

## 层叠顺序

统一使用 `global.css` 的 token：`--z-base` / `--z-raised` / `--z-popover` / `--z-sticky` / `--z-modal`。局部样式不得使用未定义的数值 `z-index`。

## 材质、边框与圆角

- 顶部栏和侧栏使用实色背景，**禁止**半透明背景与 `backdrop-filter`。
- 普通分隔线使用 `--line`，只表达结构边界。
- 弹窗使用 `--paper-strong`、完整边框和 `--shadow-modal`，遮罩使用 `--overlay` 且不加模糊。
- 普通文本标签不使用胶囊容器；只有状态、筛选条件和短标签使用紧凑徽章。
- 禁止大面积厚重阴影、粗边框和高对比度浮动面板。

### 仪器域

机器输出的统一材质，定义在 `styles/common.css`。任何承载「机器吐出的内容」的容器都应带 `.instrument` 标记。

| 元素 | 类名 | 说明 |
|---|---|---|
| 容器 | `.instrument` | 凹一层的表面：`--inst-bg` + `--inst-line` 描边 + `--radius-card` + `--inst-inset` 内阴影，等宽字体 |
| 脚注 | `.instrument-foot` | 行数、退出码、工作目录等客观事实，顶部细线分隔，等宽数字 |
| diff 行 | `.instrument-line` | `data-kind="add|del|hunk"`，配色来自 `--inst-add-*` / `--inst-del-*` |

仪器域内部必须遵守：

- **只允许扁平分区**：分区之间用 `1px solid var(--inst-line)` 分隔，分区内只用 11px 微型标签说明这一段是什么。
- **禁止嵌套圆角盒子**。工具输出若是 Markdown，其代码块和表格会再次带上 `.instrument`，必须用作用域规则把它们压平（去掉边框、圆角与背景），否则会形成「盒子里的盒子里的盒子」。
- **衔接：账本展开体不是卡片。** 活动账本的展开体（`.act-body`）是账本里的一行，必须与账本同宽，并且去掉自身的边框、圆角和外侧阴影，只保留一条 `border-top` 细线加 `--inst-inset` 内阴影。它是 `.instrument`，但要显式覆盖掉 `.instrument` 的边框与圆角——否则会在圆角账本内部再出现一层圆角轮廓，衔接处会出现内圈边线。
- **衔接：展开体与账本行的明度差必须可见。** `--inst-bg` 与 `--paper-2` 的明度差不得小于约 5%，否则展开区读起来只是「行变高了」，分隔线会显得没有来由。
- **命令用 `$` 提示符自证身份，不加文字标签**；只有待批准这种「还没执行」的状态才写「待执行命令」。输出分区保留「输出」标签，因为裸文本在分隔线后含义不明确。
- **不重复展示**：单行且不超过 64 字符的命令在活动账本行内已完整可见，展开区不再重复。
- 仪器域内的 Markdown、表格、行内代码和链接必须整体翻到 `--inst-*` 配色，并且尺寸压到机器输出的档位。

## 图标与控件

- 默认使用 `lucide-react`，不手绘已有语义的 SVG，也不使用 ASCII 字符模拟图标。
- 仅图标按钮必须提供 `aria-label`；不熟悉的图标同时提供 `title`。
- 按钮只有五种角色，同一角色必须使用同一组取值：
  1. **主操作**：`--accent` 实心 + `--on-accent` 文字。
  2. **次级**：`--fill` 底 + `--ink` 文字。
  3. **描边**：透明底 + `--line-strong` 描边 + `--ink` 文字。
  4. **危险实心**：`--danger` 实心 + `--on-danger` 文字，只用于确认动作。
  5. **危险描边**：透明底 + `--danger-line` 描边 + `--danger` 文字，用于危险入口。
- 顶栏内的次级按钮退成幽灵态（透明底 + `--muted`），降低顶栏噪音。
- 二元设置使用开关或复选框，模式切换使用分段控件，数值使用输入框、步进器或滑块，选项集合使用菜单或下拉框。
- 图标按钮悬停与激活只改变背景色和前景色，不改变几何尺寸；按下可以轻微缩放。

## 表单与浮层

- 表单标签使用 `--muted`，placeholder 使用 `--faint`。
- **输入框聚焦只把边框加深到 `--faint`**：不加外侧 `outline`、发光、主色边框或额外 `box-shadow`。
- 错误提示使用完整圆角边框、`--danger-soft` 背景、图标和文字，不使用左侧色条。
- 选择框的下拉箭头使用 `--select-chevron`，随主题切换。
- 菜单、选择器和弹出面板贴近触发控件，使用 `--paper-strong` 与 `--shadow-float`。
- 点击浮层外部或按 `Escape` 关闭非阻塞浮层。
- 危险操作必须使用红色语义，并在执行前提供清晰确认状态。

## 内容呈现

### 消息线程

一条阅读列：消息头、思考摘要、正文、活动账本、回合脚注全部左对齐，不为「名字沟槽」缩进内容。

| 元素 | 规则 |
|---|---|
| 用户消息 | 右对齐软绿气泡，`--accent-soft` 底 + `--accent-ink` 文字，最大宽度 74% |
| 代理消息 | 纯排版，无卡片容器 |
| 消息头 | 名称使用 `--muted` 13.5px/650，时间使用 `--faint` 11px 等宽数字 |
| 回合脚注 | `.message-copy-actions` 与 `.turn-foot`：展示耗时与 token 分项用量，窄屏在分项之间换行；精确计数与首响应写进 `title` |
| 进行中状态 | 使用 `--live` 与旋转图标 |

#### 线程间距

三级间距只在 `features/agent/conversation.css` 定义一次，历史渲染与流式渲染共用同一套 margin，两条路径不得各写一套。

| 用途 | 令牌 | 值 |
|---|---|---|
| 轮内块之间（思考 / 正文 / 活动账本 / 仪器 / 脚注） | `--message-content-gap` | `14px` |
| 名称行到内容，以及正文段落之间 | `--message-head-gap` | `10px` |
| 回合之间 | `--turn-gap` | `24px` |

- 轮内所有块使用同一个 `--message-content-gap`；相邻块的 margin 折叠后取较大值，仍收敛到同一档。
- 同一次执行的后续消息（continuation）使用轮内间距，不使用回合间距。
- 回合脚注与上方内容之间同样是轮内间距，靠字号与颜色而不是额外留白来表达「脚注」层级。

### 思考摘要

单行摘要 + 可展开内容，不是独立卡片。

- `.thinking-toggle` 高 24px，11px 文字，`--faint`，悬停变 `--fill` 底并转为 `--ink`。
- 展开后隐藏摘要（避免与正文重复），只旋转箭头。
- 展开内容左侧用 `1px solid var(--line)` 作为引线。

### 活动账本

一次 agent 回合里的**有先后的动作**（工具调用）排成一张账本，保持发生顺序，不占整行卡片。

| 元素 | 规则 |
|---|---|
| 容器 `.acts` | 内嵌块表面：`--paper-2` 底 + `--line` 描边 + `--radius-card`；一次运行里的连续调用合并为同一张账本 |
| 行 `.act-row` | 高 28px，四列：60px 工具名 / 弹性参数 / 72px 耗时或状态 / 14px 状态标记，列间距 12px |
| `.act-name` | `--mono` 12.5px/650，`--ink`，是这一行最重的一档 |
| `.act-arg` | `--mono` 12.5px，`--muted`，超出省略并在 `title` 提供全文 |
| `.act-time` | `--mono` 11px，`--faint`，**固定宽度 + 右对齐 + 等宽数字**，在各行之间形成一条整齐的竖线 |
| `.act-mark` | 13px 图标，必须带可访问名称，不能只靠颜色表达状态 |
| 展开体 `.act-body` | 仪器域（同时带 `.instrument`），承载参数与输出 |

右列只放**一个值**，避免「运行中 · 12s」这类组合把参数列挤成逐行抖动：

- 异常状态（待批准、失败）显示**状态词**；
- 其余状态显示**耗时**（`DurationLabel` 传空 `label`，只输出数字）；
- 两者都由标记图标的可访问名称补齐，语义不丢失。

状态四档语义：

| 档位 | 适用状态 | 表现 |
|---|---|---|
| `done` | `completed` | `--accent` 标记 |
| `live` | `running` / `retrying` | `--live-soft` 软底 + `--live-ink` 名称 + 旋转标记 |
| `wait` | `awaiting_approval` | `--warn-soft` 软底 + `--warn-ink` 名称 |
| `bad` | `failed` / `timeout` | `--danger-soft` 软底 + `--danger-ink` 名称 |

进行中、失败、超时与待批准默认展开，其余默认折叠。

### 审批闸口

待批准的操作固定在输入区正上方，一次只显示一条，批准后自动露出下一条。

- 它是全屏唯一的实心提醒色块：`--warn-soft` 底 + `--warn-line` 描边 + `--radius-card`。
- 标题使用 `--warn-ink`，命令与路径使用等宽字体。
- 批准按钮是实心 `--warn` + `--on-warn`；拒绝按钮是描边档。
- 队列大于一条时显示 `1 / N` 计数。
- 审批决定只有这一个入口，活动账本内不再重复一组按钮。

### 代码块与 diff

- 代码块容器带 `.instrument`，工具条高 34px，语言标签与增删行数使用仪器域次级色。
- 复制按钮 24px，位于右上角，使用 `--inst-dim`，悬停 `--inst-fill`。
- diff 行使用 `--inst-add-*` / `--inst-del-*`，与仪器域绑定，不用于纸张内容。
- 表格属于阅读内容，留在纸上：`--paper` 底 + `--line` 描边。

### 状态徽章

- 高 22px，内边距 `0 8px`，圆角 `--radius-chip`，字号 11px/650，圆点 6px。
- 软底 + 描边 + 深色文字三件套，取值来自 `--accent-*` / `--warn-*` / `--danger-*` / `--fill`。
- 协作卡片使用徽章；活动账本使用行内标记。

### 协作结果

子代理与并行任务属于阅读内容，留在纸上：`--paper-2` 卡片 + `--line` 描边 + `--radius-card`，进度条三态使用 `--accent` / `--live` / `--danger`。

### 空状态

- 无卡片容器：图标方块 + 标题 + 说明 + 特性列表 + 快捷键提示。
- 标题使用 `--font-size-display`，说明使用 `--font-size-body`。
- 页面级留白使用固定值，不使用 `vh` 或 `clamp()`。

## 交互与动效

- 动效只说明状态变化和空间关系，不用于装饰或延迟反馈。
- 加载过程不使用长时间淡出、连续滚动或阻塞式动画。
- 所有动效都必须在 `prefers-reduced-motion: reduce` 下被压缩或停转。
- 「正在发生」的呼吸动画只出现在活动状态标记与顶栏状态点上。

## 响应式

- 超过 `1180px` 时显示完整三栏；`1180px` 及以下收起 Agent 侧栏，`860px` 及以下收起项目侧栏，主内容占满可用宽度。
- 主栏内容列（Page、会话阅读列）随主栏宽度按 80% 比例伸缩并受上下限约束：宽屏不退回固定阅读宽度，中等窗口不窄于原有阅读宽度；会话消息、审批闸口与输入区共用同一内容宽度。
- 项目侧栏收起时，顶部栏左侧保留 `Menu` 图标入口；导航抽屉沿用侧栏视觉，宽度不超过 `320px`。
- `720px` 以下减少页面边距，活动账本收紧列宽；`460px` 以下压缩顶部栏与弹窗间距，表单单列排列，操作按钮使用等宽布局。
- 移动端触控目标必须可操作：图标按钮不小于 `32px`，主要按钮不小于 `36px` 高度。
- 不通过缩小到难以阅读的字号解决空间不足，优先换行、重排或隐藏次要信息。

## 无障碍

- 所有交互元素必须可通过键盘操作，并具有清晰的可访问名称。
- 图标不能作为状态或操作含义的唯一载体；活动账本的标记必须带 `aria-label`。
- 文字、图标和背景之间保持足够对比度：主文字 ≥ 13:1，次级 ≥ 7:1，辅助 ≥ 4.7:1，非文字状态标记 ≥ 3:1。
- 焦点反馈必须可辨识：按钮使用 `--focus-ring`，输入框只改变边框颜色。
- 禁用状态不能只降低透明度到难以辨识。

## 禁止项

- 不使用文字或 ASCII 字符模拟图标。
- 不使用负字距、视口比例字号、装饰性渐变或背景光球。
- 不使用半透明背景与 `backdrop-filter`。
- 不使用左侧色条表达选中状态。
- 不嵌套卡片，不把普通页面区块设计成浮动卡片。
- 不写裸色值、裸字号、裸圆角或裸阴影；不在组件内重复定义 `praxis-spin` 关键帧。
- 不使用 `transition: all`。
- 不在组件样式中写主题分支（`[data-theme=...]` 只允许出现在 `theme-dark.css`）。

## 验证

前端样式或组件变更完成后，至少运行：

```bash
cd frontend
npm run check
```

同时检查白天与夜间两个主题、桌面端、`1180px`、`860px`、`720px`、`460px` 断点、`320px` 最小窗口和短窗口，以及键盘焦点、错误态、空状态、加载态和 `prefers-reduced-motion`。
