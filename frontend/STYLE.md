# Praxis Frontend Style Guide

状态：活跃规范

这份文档是 Praxis 前端视觉风格的唯一入口。所有新增或修改的前端组件、页面、交互状态和样式，都必须遵守这里的规则；如果稳定的视觉决策发生变化，必须在同一次变更中更新本文件。

## 设计方向

Praxis 使用 Apple 风格的浅色桌面工作区：克制、清晰、安静，优先保证长期使用时的扫描效率。Apple 风格指系统字体、语义化颜色、低对比度分隔、半透明材质和稳定的交互反馈，不指复制 Apple 标志或具体产品界面。

- 默认只使用浅色界面：页面背景为 `#f5f5f7`，内容表面使用白色或半透明白色。
- 不使用装饰性渐变、渐变光球、bokeh、噪点纹理或无业务意义的插画背景。
- 不使用荧光绿、深色霓虹、厚重拟物阴影或高饱和多色面板。
- 页面区域保持开放布局；卡片只用于重复条目、弹窗等确实需要被框定的内容，消息线程使用平面 Transcript。
- 不在前端复制 Agent 状态机或持久化规则；视觉层只呈现 binding 提供的状态。

## 颜色令牌

颜色统一在 `src/styles/global.css` 的 `:root` 中定义。组件样式优先使用令牌，不要在局部重新发明近似颜色。

| 用途 | 令牌 | 当前值 |
|---|---|---|
| 主文字 | `--ink` | `#1d1d1f` |
| 次级文字 | `--ink-secondary` | `#6e6e73` |
| 辅助文字 | `--ink-tertiary` | `#86868b` |
| 主操作 | `--blue` | `#007aff` |
| 主操作悬停 | `--blue-strong` | `#0066d6` |
| 选中背景 | `--blue-soft` | `#e8f2ff` |
| 成功/就绪 | `--green` | `#34c759` |
| 执行/提醒 | `--orange` | `#ff9500` |
| 错误/失败 | `--red` | `#ff3b30` |
| 页面背景 | - | `#f5f5f7` |
| 细分隔线 | `--line` | `rgba(60, 60, 67, 0.16)` |
| 强分隔线 | `--line-strong` | `rgba(60, 60, 67, 0.26)` |

状态颜色必须保持语义稳定：绿色表示 ready/idle/waiting，橙色表示 executing/pausing，红色表示 paused/interrupted/failed，灰色表示 closed 或未知状态。

## 字体与排版

- 使用系统字体栈：`-apple-system, BlinkMacSystemFont, "SF Pro Display", "SF Pro Text", "Helvetica Neue", Arial, sans-serif`。
- 不引入新的品牌字体，也不恢复已移除的 Nunito 等非系统字体作为默认字体。
- `letter-spacing` 必须为 `0`；禁止负字距和装饰性字距。
- 正文基准字号为 `15px`，行高为 `1.45`。
- 标题使用固定桌面字号，并在移动端断点切换到另一档固定字号；禁止用 `vw` 或 `clamp()` 让字体随视口连续缩放。
- 小标题和状态文本使用字重、颜色和层级表达信息，不依赖全大写或过宽字距制造强调。
- 文本必须在父容器内完整显示；长项目名、路径、Session 标题和 Agent ID 使用省略号处理。

## 材质、边框与圆角

- 顶部栏和侧栏使用半透明白色与 `backdrop-filter`，实现轻量毛玻璃材质；内容背景保持平实，不添加背景渐变。
- 普通分隔线使用 `--line`，只表达结构边界，不作为装饰。
- 普通输入框、按钮和列表行使用约 `8px` 至 `10px` 圆角；不要使用胶囊形容器包装普通文本。
- Agent 回复和执行失败保持平面，不使用气泡、圆角、分隔线或浮层阴影；用户消息正文使用浅蓝背景、细边框和 `10px` 圆角的紧凑气泡。弹窗是独立浮层，可以使用 `18px` 左右圆角和柔和浮层阴影。
- 阴影必须低扩散、低透明度，只用于顶部栏、消息层次和弹窗；禁止大面积厚重阴影。
- 输入框聚焦时只改变边框颜色或背景色。禁止 `outline`、外发光或额外 `box-shadow`。

## 组件规则

### 顶部栏

- 顶部栏保持 `64px` 左右高度、细底边和半透明背景。
- 品牌标识可以使用 Praxis 自有的黑白方形标记，但不能伪造 Apple 标志。
- 健康状态使用小圆点和文字，颜色必须遵循状态令牌。
- 刷新、关闭、添加、搜索等明确工具优先使用 Lucide 图标；图标按钮必须有 `aria-label`，不熟悉的图标必须有 `title`。

### 项目与 Session 侧栏

- 项目层级使用无边框 disclosure chevron；展开为向下，收起为向右，不使用带边框的小方框。
- Session 选中态使用浅蓝背景、蓝色文字和轻微边框；禁止使用蓝色左竖条或树形连接竖线表达选中。
- 项目下的 Session 总数使用右对齐的低对比度纯数字；只有未读、告警等需要强调的语义才使用徽标胶囊。
- 列表行应保持整行可点击，悬停和选中使用短时背景过渡，不改变布局尺寸。
- 工具图标默认使用低对比度半透明底色，悬停/激活时变为蓝色语义，不使用高饱和常驻填充。

### Session 内容与消息

- 消息线程切换到新 Session 时必须直接显示最后一条，不使用滚动动画追赶到底部。
- 同一 Session 收到新消息时可以使用短时平滑滚动。
- 消息按自身内容高度从顶部连续排列，剩余空间留在消息线程底部，不能被 Grid 拉伸成消息间的空白。
- 可滚动消息线程必须为滚动槽预留稳定空间，滚动条固定在中央页面区域右侧而非消息阅读列右侧；右对齐消息不能贴住或被滚动条覆盖，滚动槽使用约 `12px` 的适中宽度、低对比度滑块和透明轨道。
- Session 异步切换期间不显示 `Select a Session`、`No Sessions Yet` 或 Agent 提示文案；使用无文字加载占位，避免旧内容留影。
- Agent 回复左对齐，用户消息右对齐；用户消息使用浅蓝色紧凑气泡，Agent 消息和执行失败保持平面。错误使用红色语义但不能只依赖红色传达信息。
- Agent 回复正文使用安全的 CommonMark / GFM 渲染；支持标题、列表、代码、链接和表格，原始 HTML 不渲染。用户输入按原始纯文本显示，并保留换行。
- Fenced code block 显示语言标签和 Copy 图标按钮；Markdown 表格使用紧凑表头、细分隔线、Copy 图标按钮与窄屏横向滚动，复制结果为 tab-separated text；任务列表使用只读的原生尺寸复选框。
- Agent 已接受输入但尚未收到首个输出 delta 时，在消息线程中显示左对齐的橙色 `Thinking` 状态与轻量加载图标；首个 delta 必须直接替换该状态，最终内容仍由持久化历史接管。
- 每条消息正文下方提供 Copy 图标按钮，复制正文后短暂显示 Check 状态；按钮必须有 `title` 和 `aria-label`，并跟随消息方向对齐。
- 无消息状态使用占满消息区域的居中消息图标和简短文案，不使用横向分隔线或卡片背景。

### 表单与弹窗

- 主操作使用 Apple 蓝色实心按钮，次操作使用浅灰或透明按钮，危险操作使用低透明度红色按钮。
- 表单标签使用次级文字；placeholder 使用辅助文字，不得与正文争夺层级。
- Session 输入区使用胶囊式白色 composer：左侧为辅助入口，中间是可自动增高的 textarea，右侧放置模式提示、不可用时置灰的语音入口和圆形 Send/Stop 主操作；所有控件保持在同一行，并固定在对话内容区底部，且层叠顺序高于消息线程。输入聚焦时不改变 composer 外边框为蓝色。
- 模型使用紧凑触发器，点击后在其上方打开模型菜单，菜单中心与触发器中心对齐，并显示模型名、提供商与当前选中态；思考强度使用紧凑触发器，点击后在其上方留出明确间距打开带档位标签的滑块浮层。两种浮层互斥，点击控件外部或按 Escape 关闭；拖动滑块即时切换强度。
- 弹窗使用半透明白色浮层、背景模糊和完整边框；错误提示使用完整圆角边框，不使用左侧色条。
- 移动端弹窗贴近底部、保留安全边距，操作按钮在窄屏下等宽排列。

## 交互与动效

- 背景、边框、颜色和轻微缩放过渡通常为 `140ms` 左右；内容入场不超过 `180ms`。
- 切换 Session 时优先保证内容一致性：旧请求不得覆盖新选择，旧消息和输入草稿不得残留。
- 所有动效都必须在 `prefers-reduced-motion: reduce` 下被压缩或禁用。
- 禁止为了“丝滑”给数据加载过程增加长时间淡出、连续滚动或阻塞式动画。

## 响应式规则

- 桌面端使用三栏工作区；`900px` 以下隐藏 Projects 与 Agents 两侧栏并只显示主区域，`720px` 以下保持主区域全高和底部常驻 composer，仅消息线程滚动，`460px` 以下压缩顶部栏和弹窗操作。
- 工具栏、按钮、输入框、列表行和固定格式区域必须保持稳定尺寸，避免内容变化导致布局跳动。
- 不为字号使用视口比例缩放；通过断点切换固定字号和间距。
- 移动端必须保持触控目标可操作，图标按钮不小于 `32px`，主要按钮不小于 `36px` 高度。

## 禁止项检查清单

- 不使用文字或 ASCII 字符模拟图标。
- 不使用负字距、`vw` 字号、渐变光球或装饰性背景。
- 不用左侧色条、连接线或粗重边框表达选中态。
- 不在切换期间显示旧 Session 内容、启动文案或旧输入草稿。
- 不绕过现有颜色令牌、Lucide 图标和输入框聚焦规则。

## 修改后的验证

前端样式或组件变更完成后，至少运行：

```bash
cd frontend
npm run build
```

同时检查：桌面端三栏、`900px`、`720px` 和 `460px` 断点；Session 切换、Agent 切换、弹窗错误态、输入框聚焦态和 `prefers-reduced-motion`。
